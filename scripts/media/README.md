# เครื่องมือสร้างสื่อ

- `local/render-talevo-promo.py` — สร้างคลิปประชาสัมพันธ์จาก assets ของแอป
- `local/render-talevo-promo-reference.py` — สร้างคลิปจากไฟล์อ้างอิงในเครื่อง
- ผลลัพธ์อยู่ที่ `deliverables/talevo-promo/` เหมือนเดิม

`local/` ถูก ignore เพราะมีเส้นทางส่วนตัว ไฟล์แนบ และการตั้งค่าของเครื่อง.
ก่อนเผยแพร่เครื่องมือเหล่านี้ ต้องเปลี่ยน private paths เป็น arguments/config
และตรวจสิทธิ์สื่อกับข้อมูลส่วนบุคคลในภาพและเสียงก่อน.
ไม่ได้ render วิดีโอใหม่ในการจัดโฟลเดอร์ครั้งนี้.
