# ผลงานส่งมอบ

เก็บผลลัพธ์ที่ส่งให้ผู้ใช้ แยกโฟลเดอร์ตามชื่องาน เช่น `talevo-promo/`.
เก็บเครื่องมือสร้างงานไว้ใน `scripts/` และสื่อที่แอปใช้จริงไว้ใน `public/assets/`.

ก่อนเพิ่มไฟล์ขึ้น GitHub ตรวจว่าไม่มีข้อมูลผู้ใช้จริง, secrets, browser session,
database dump หรือ metadata ส่วนบุคคลที่ไม่ได้ตั้งใจเผยแพร่.
ไฟล์วิดีโอและไฟล์ขนาดใหญ่ควรเผยแพร่ผ่านช่องทางส่งมอบที่เหมาะสมหลังตรวจขนาดและสิทธิ์;
อย่าเพิ่มทั้งโฟลเดอร์ด้วย `git add .`.
